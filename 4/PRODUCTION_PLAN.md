# Video 04 제작 순서 (v2 대본 기준)

대상: `4/script_04_shamanism_v2.md` (10분, 실록 원문 카드 6개)
목표: 새 기준(원문 카드 + 썸네일 템플릿)을 적용한 첫 영상

---

## 원칙 3개

1. **대본 확정 전에는 TTS를 뽑지 않는다.** 문장 하나 바뀌면 오디오 전체를 다시 뽑아야 함.
2. **인트로(5초)는 자막·챕터 확정 전에 넣는다.** 나중에 붙이면 모든 타임스탬프가 5초씩 어긋남.
3. **실록 카드는 자막이 아니라 이미지로 굽는다.** Whisper 자막과 섞이면 겹침/오타 발생.

---

## Phase 0 — 대본 잠금 (0.5일)

- [x] 실록 인용 원문 대조 (6건 확정, 2건 2차 자료) (sillok.history.go.kr)
- [ ] 영어 번역 톤 통일 (직역 유지, 과장 금지)
- [ ] TTS 발음 표기 추가: Joseon, Sejong, Yeongjo, Yeonsangun, Seongsucheong, Makrye, mudang, gut, sinbyeong, naerim, Hwalinseo, Noryangjin, Myeongseong
- [ ] 최종 워드카운트 확인 (1,400~1,500자 → 9:30~10:30)

**완료 기준**: 읽으면서 고칠 곳이 없고, 인용문에 의심 가는 곳이 0개.

---

## Phase 1 — TTS (0.5일)

- [x] 섹션 단위 8개 청크 분할 완료 (`4/tts_chunks/`) (콜드오픈 / 법 / 성수청 / 단속 / 이유 / 생존 / 신병 / 클로징)
- [ ] ElevenLabs(EC2 `/tts`)로 청크별 생성
- [ ] 청크 사이 무음 0.4~0.6초로 붙이기
- [ ] 전체 길이 측정 (목표 9:30~10:30)
- [ ] 이름 발음 확인 (Sejong, Yeongjo, Makrye)

**완료 기준**: 오디오 1개, 길이 목표 범위, 발음 오류 0개.

> 섹션 단위로 뽑는 이유: 한 섹션만 다시 뽑으면 되니까. 전체 한 번에 뽑으면 수정 비용이 10배.

---

## Phase 2 — 자막 (0.5일)

- [ ] Whisper로 SRT 생성 (영어)
- [ ] 고유명사 표기 수정 (Joseon, Sejong, Yeongjo, Seongsucheong, Makrye, Hwalinseo)
- [ ] 한 줄 42자 이내로 재분절
- [ ] 카드 구간(0:00, 0:40, 2:10, 3:40, 5:10)에는 자막 비우기

**완료 기준**: 10분 재생하며 자막 어긋남 0건.

---

## Phase 3 — 이미지 (1~2일) ※ Phase 1과 병행 가능

- [x] 샷 리스트 + 프롬프트 50개 완료 (`4/prompts/images.md`)
- [ ] 레오나르도 프롬프트 작성 (스타일 고정: 조선, 등불, 안개, 저채도)
- [ ] 1차 생성 → 60~70장 → 50장 선별
- [x] 실록 카드 6장 제작 완료 (`4/source_cards/`) (검정 배경 + 한글 + 영어 + 출처)
- [ ] 카드 가독성 모바일 확인 (한글 최소 44px)

**완료 기준**: 모든 샷이 대본 구간과 1:1 매칭, 카드 6장 육안 확인.

---

## Phase 4 — 조립 (0.5일)

- [ ] 타임라인 작성 (이미지 + 카드 + 길이)
- [ ] **인트로 5초 선두 삽입**
- [ ] FFmpeg: Ken Burns + 자막 burn-in + 오디오
- [ ] BGM: 나레이션 -6dB 기준, BGM -24~-26dB, 카드 구간은 -20dB
- [ ] 라우드니스 -14 LUFS 정규화

**완료 기준**: 1080p mp4, A/V 싱크 오차 0.2초 이내.

---

## Phase 5 — 검수 (0.5일)

- [ ] 처음부터 끝까지 1회 시청 (배속 금지)
- [ ] 모바일 화면에서 자막·카드 읽히는지
- [ ] 오디오 클리핑/무음 구간 확인
- [ ] 사실 확인: 인용 6건 + 연도
- [ ] 저작권: 영화 포스터 3초 이내, 출처 표기

**완료 기준**: 치명 결함 0개. 사소한 결함은 목록만 남기고 다음 영상에 반영.

---

## Phase 6 — 업로드 준비 (0.5일) ※ Phase 4와 병행 가능

- [ ] 썸네일 3안 제작 → 1안 확정 (`BANNED FOR 500 YEARS`)
- [ ] 제목 A/B/C 중 확정
- [ ] 설명 + 챕터 (최종 렌더 기준으로 재계산)
- [ ] 태그 세트, 고정 댓글, 최종화면
- [ ] Shorts 3개 추출 (강한 구간 45초)

**완료 기준**: 업로드 폼에 붙여넣기만 하면 되는 상태.

---

## Phase 7 — 업로드 + 관찰

- [ ] 공개 예약 (한국 시간 화/목 저녁, 미국 동부 오전)
- [ ] 업로드 후 48시간: CTR·평균 시청 지속률 확인
- [ ] Shorts 3개를 3일간 분산 게시

**판정 기준 (4편 누적 후)**
- CTR 3% 미만 → 썸네일/제목 문제
- 지속률 30% 미만 → 초반 30초 또는 길이 문제
- 둘 다 정상인데 노출 없음 → 소재/경쟁 문제
